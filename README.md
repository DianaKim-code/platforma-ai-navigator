# Платформа — AI‑навигатор

**Текущая версия продукта: MVP v2.**

Статический веб‑прототип бережного AI‑навигатора. Он проводит пользователя через основной и уточняющие вопросы, формирует персональное отражение ситуации, объясняет логику результата, предлагает предварительную формулировку запроса и небольшую практику. Перед переходом к записи пользователь оставляет обратную связь.

MVP включает основной сценарий и уточняющие ветки, маршруты результата R1–R4, отдельный безопасный экран при запросе срочной помощи, персональное отражение, объяснение результата, предварительный запрос, практику и обратную связь перед переходом к записи. После сохранения обратной связи пользователь видит персонализированную карточку рекомендованного специалиста и может открыть профиль Дианы или обсудить результат в WhatsApp.

## Структура проекта

- `index.html` — интерфейс, стили, сценарии ветвления, формирование результата и отправка данных.
- `specialist-diana.html` — профиль Дианы в формате будущего каталога специалистов Платформы.
- `expert-diana.jpg` — фотография для карточки рекомендации и страницы профиля.
- `images/hero-platforma.png` — декоративное изображение первого экрана.
- `README.md` — документация проекта.
- `.nojekyll` — отключает обработку Jekyll при публикации статического сайта через GitHub Pages.

## Локальный запуск

Проект не требует сборки и установки зависимостей.

Самый простой способ — открыть `index.html` в браузере. Для проверки в условиях, близких к GitHub Pages, можно запустить локальный HTTP‑сервер из папки проекта:

```bash
python -m http.server 8000
```

После этого открыть [http://localhost:8000](http://localhost:8000).

## Публикация через GitHub Pages

1. Отправить проект в ветку `main` репозитория `DianaKim-code/platforma-ai-navigator`.
2. На GitHub открыть **Settings → Pages**.
3. В разделе **Build and deployment** выбрать **Deploy from a branch**.
4. Выбрать ветку `main`, папку `/ (root)` и нажать **Save**.
5. После завершения публикации сайт будет доступен по адресу:
   `https://dianakim-code.github.io/platforma-ai-navigator/`.

## Интеграция с Google Apps Script

После заполнения обязательной обратной связи браузер отправляет JSON‑данные методом POST в существующий Google Apps Script. Скрипт записывает результаты в подключённую Google Таблицу. После успешного сохранения появляется карточка специалиста. При переходе по кнопке «Обсудить результат» дополнительно отправляется событие со значением `bookingClicked: true`, после чего открывается готовое сообщение в WhatsApp.

Интеграция работает напрямую из статической страницы и не требует отдельного серверного приложения.

## Тестируемые пользовательские метрики

- выбранная сфера и основное переживание;
- ответы на уточняющие вопросы;
- длительность ситуации, влияние на жизнь и предыдущие попытки;
- желаемый результат, формат поддержки и уровень ресурса;
- сформированный маршрут R1–R4;
- оценка ясности результата по шкале 1–5;
- доверие к рекомендации по шкале 1–5;
- узнавание себя в результате;
- готовность к следующему шагу;
- свободный комментарий;
- факт завершения сценария;
- готовность к записи и факт перехода к записи.

## Важно

- URL Google Apps Script находится в константе `ENDPOINT` в `index.html`. **Не меняйте `ENDPOINT` без отдельного продуктового и технического решения:** это разорвёт текущую интеграцию с Google Таблицей.
- Ссылка кнопки записи находится в элементе с `id="booking"`.
- Перед публикацией рекомендуется пройти весь сценарий на компьютере и мобильном устройстве и проверить появление тестовой строки в Google Таблице.
